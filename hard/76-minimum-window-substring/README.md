# 最小覆盖子串

- LeetCode 题号：76
- 难度：困难
- 题目链接：[最小覆盖子串 - 力扣](https://leetcode.cn/problems/minimum-window-substring/description/)

## 题目描述

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 `s` 中的最短窗口子串，使得该子串包含 `t` 中的每一个字符，包括重复字符。如果没有这样的子串，返回空字符串 `""`。

测试用例保证答案唯一。

## 函数签名

```go
func minWindow(s string, t string) string
```

## 示例

### 示例 1

```text
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

### 示例 2

```text
输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
```

### 示例 3

```text
输入：s = "a", t = "aa"
输出：""
解释：t 中两个字符 'a' 均应包含在 s 的子串中，因此没有符合条件的子字符串。
```

## 数据范围

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 10^5`
- `s` 和 `t` 由英文字母组成。

## 解题提示

可以使用滑动窗口维护 `s` 的一个连续区间，并用哈希表记录 `t` 中每个字符需要出现的次数。当窗口满足覆盖条件时，尝试不断收缩左边界，以寻找最短答案。

进阶：设计一个 `O(m + n)` 时间复杂度的算法。
