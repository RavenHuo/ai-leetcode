# 有效的括号

- LeetCode 题号：20
- 难度：简单
- 题目链接：[有效的括号 - 力扣](https://leetcode.cn/problems/valid-parentheses/description/)

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

## 函数签名

```go
func isValid(s string) bool
```

## 示例

### 示例 1

```text
输入：s = "()"
输出：true
```

### 示例 2

```text
输入：s = "()[]{}"
输出：true
```

### 示例 3

```text
输入：s = "(]"
输出：false
```

### 示例 4

```text
输入：s = "([])"
输出：true
```

### 示例 5

```text
输入：s = "([)]"
输出：false
```

## 数据范围

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成。

## 解题提示

可以使用栈保存尚未闭合的左括号。遇到右括号时，检查栈顶左括号是否与其匹配；遍历结束后，栈必须为空。
