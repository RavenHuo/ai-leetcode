# 724. 寻找数组的中心下标

- 难度：简单
- LeetCode 链接：https://leetcode.cn/problems/find-pivot-index/

给你一个整数数组 `nums`，请计算数组的中心下标。

数组中心下标的定义是：其左侧所有元素相加之和等于右侧所有元素相加之和的下标。

如果中心下标位于数组最左端，那么左侧数之和视为 `0`；如果中心下标位于数组最右端，那么右侧数之和视为 `0`。

如果数组有多个中心下标，应返回最左边的那个。如果不存在中心下标，返回 `-1`。

## 示例

### 示例 1

输入：`nums = [1,7,3,6,5,6]`

输出：`3`

### 示例 2

输入：`nums = [1,2,3]`

输出：`-1`

### 示例 3

输入：`nums = [2,1,-1]`

输出：`0`

## 数据范围

- `1 <= nums.length <= 10^4`
- `-1000 <= nums[i] <= 1000`

## 解题提示

先计算数组总和，再从左到右维护左侧元素和。当前位置右侧元素和可以通过“总和 - 左侧和 - 当前元素”得到。
