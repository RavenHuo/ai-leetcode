# 二叉树的前序遍历

- 牛客题目标识：BM23
- 难度：简单
- 题目链接：[二叉树的前序遍历 - 牛客网](https://www.nowcoder.com/practice/5e2135f4d2b14eb8a5b06fab4c938635)

## 题目描述

给你二叉树的根节点 `root`，返回它节点值的前序遍历。

前序遍历的访问顺序是：根节点、左子树、右子树。

## 函数签名

```go
func preorderTraversal(root *TreeNode) []int
```

其中二叉树节点定义为：

```go
type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}
```

## 输入格式

输入一棵二叉树的根节点 `root`。牛客网示例使用层序序列表示二叉树，`#` 表示空节点。

## 输出格式

返回二叉树节点值的前序遍历结果。

## 数据范围

- 二叉树节点数量满足题目要求。
- 二叉树节点值为整数。
- 树的各节点值各不相同。
- 空树返回空数组。

## 示例

### 示例 1

```text
输入：{1,#,2,3}
输出：[1,2,3]
```

### 示例 2

```text
输入：{1,2,3,4,5}
输出：[1,2,4,5,3]
```

### 示例 3

```text
输入：{}
输出：[]
```

## 解题提示

可以使用递归按照“根、左、右”的顺序访问节点，也可以使用栈模拟递归过程。
