# 删除有序链表中重复的元素-I

- 牛客题目标识：BM15
- 难度：简单
- 题目链接：[删除有序链表中重复的元素-I - 牛客网](https://www.nowcoder.com/practice/c087914fae584da886a0091e877f2c79)

## 题目描述

删除给出链表中的重复元素（链表中元素从小到大有序），使链表中的所有元素都只出现一次。

例如：给出的链表为 `1 -> 1 -> 2`，返回 `1 -> 2`；给出的链表为 `1 -> 1 -> 2 -> 3 -> 3`，返回 `1 -> 2 -> 3`。

## 输入格式

输入一个按从小到大排列的单链表头节点 `head`。

## 输出格式

返回删除重复元素后的单链表头节点。

## 数据范围

- `0 <= n <= 100`
- `|val| <= 100`
- 链表中的元素已经按照从小到大的顺序排列。

## 示例

### 示例 1

输入：`{1,1,2}`

输出：`{1,2}`

### 示例 2

输入：`{1,1,2,3,3}`

输出：`{1,2,3}`

### 示例 3

输入：`{}`

输出：`{}`

## 解题提示

遍历链表，比较当前节点和下一个节点的值。如果相同，就跳过下一个节点；如果不同，再移动当前指针。整个过程只需要修改节点指针。

目标复杂度：时间 `O(n)`，额外空间 `O(1)`。
