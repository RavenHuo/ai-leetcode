# 链表中环的入口结点

- 牛客网题目标识：BM7
- 难度：中等
- 题目链接：https://www.nowcoder.com/practice/253d2c59ec3e4bc68da16833f79a38e4

## 题目描述

给一个长度为 `n` 的链表，若其中包含环，请找出链表环的入口结点；否则返回 `nil`。

## 输入与输出

输入由入环前的链表部分和环的部分组成。返回环的入口结点；如果没有环，返回 `nil`。

## 数据范围

- `0 <= n <= 100000`
- 时间复杂度：`O(n)`
- 额外空间复杂度：`O(1)`

## 样例

1. 入环前 `{1,2}`，环部分 `{3,4,5}`，返回结点值 `3`。
2. 入环前 `{1}`，环部分 `{}`，返回 `nil`。
3. 入环前 `{}`，环部分 `{2}`，返回结点值 `2`。

## 解题提示

使用快慢指针判断是否相遇。相遇后，将一个指针移回头节点，两个指针同步移动，再次相遇的位置就是环的入口。
