# 链表中的节点每 k 个一组翻转

- 牛客网题目标识：BM3
- 难度：中等
- 题目链接：https://www.nowcoder.com/practice/b49c3dc907814e9bbfa8437c251b028e

## 题目描述

将给出的链表中的节点每 `k` 个一组翻转，返回翻转后的链表。如果链表中的节点数不是 `k` 的倍数，将最后剩下的节点保持原样。不能更改节点中的值，只能更改节点本身。

## 输入格式

链表头节点 `head` 和正整数 `k`。

## 输出格式

返回每 `k` 个节点翻转后的链表头节点。

## 数据范围

- 链表节点数为 `n`，`1 <= k <= n`
- 不能修改节点值，只能修改 `Next` 指针
- 时间复杂度要求为 `O(n)`，额外空间复杂度要求为 `O(1)`

## 样例

1. `{1,2,3,4,5}`, `k = 2` → `{2,1,4,3,5}`
2. `{1,2,3,4,5}`, `k = 3` → `{3,2,1,4,5}`
3. `{}`, `k = 1` → `{}`

## 解题提示

可以使用哨兵节点。每次先检查剩余链表是否至少有 `k` 个节点，确认足够后使用三个指针原地翻转当前分组，并连接前后分组。
