# 实现一个线程安全的令牌桶限流器

- 牛客网题目标识：`token-bucket-limiter`
- 难度：中等
- 牛客网题目链接：https://www.nowcoder.com/discuss/924737812140666880

请使用 Go 实现一个简单的令牌桶限流器。

令牌桶以固定速率生成令牌，桶的容量有限。每次请求到来时需要消耗一个令牌：有令牌则允许请求并消耗一个令牌，没有令牌则拒绝请求，令牌数量不能超过最大容量。

## 要求

1. 支持设置桶容量 `capacity` 和每秒生成的令牌数 `rate`。
2. `Allow` 方法返回当前请求是否被允许。
3. 根据请求到达时间自动补充令牌。
4. 令牌数量不能超过桶容量。
5. 多个 Goroutine 并发调用 `Allow` 时不能出现数据竞争。
6. `Allow` 接收请求发生时间 `now`，便于编写确定性的单元测试。

## 示例

### 示例 1

桶容量为 `2`，初始有 `2` 个令牌，连续请求 3 次，结果为：`true`、`true`、`false`。

### 示例 2

桶容量为 `2`，速率为每秒 `1` 个令牌，消耗完令牌后等待 `1` 秒，再次请求应该被允许。

### 示例 3

多个 Goroutine 并发调用 `Allow` 时，仍然只能按照实际令牌数量允许请求。

## 解题提示

使用互斥锁保护令牌数量和上次补充时间。根据 `now` 与 `lastTime` 的时间差计算新增令牌，并将令牌数量限制在桶容量以内。可以使用浮点数保存令牌数量，避免丢失小数时间产生的令牌。
