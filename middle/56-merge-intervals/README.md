# 56. 合并区间

- 难度：中等
- LeetCode 链接：https://leetcode.cn/problems/merge-intervals/

以数组 `intervals` 表示若干个区间集合，其中单个区间为 `intervals[i] = [starti, endi]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

## 示例

### 示例 1

输入：`intervals = [[1,3],[2,6],[8,10],[15,18]]`

输出：`[[1,6],[8,10],[15,18]]`

### 示例 2

输入：`intervals = [[1,4],[4,5]]`

输出：`[[1,5]]`

### 示例 3

输入：`intervals = [[1,10],[2,3]]`

输出：`[[1,10]]`

## 数据范围

- `1 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= starti <= endi <= 10^4`

## 解题提示

先按照区间左端点排序。遍历时，如果当前区间的左端点不大于结果中最后一个区间的右端点，则两个区间重叠，更新最后一个区间的右端点；否则加入新的区间。
