# 字母异位词分组

来源：[LeetCode 49 - 字母异位词分组](https://leetcode.cn/problems/group-anagrams/description/)

难度：中等

## 题目描述

给定一个字符串数组 `strs`，请将字母异位词组合在一起。可以按任意顺序返回结果。

字母异位词是由重新排列原单词的所有字母得到的新单词，两个字符串中的每个字母出现次数必须相同。

## 输入格式

- 第一行输入一个整数 `n`，表示字符串数量。
- 第二行输入 `n` 个仅包含小写英文字母的字符串。

## 输出格式

输出分组后的字符串数组。各组以及每组内部字符串的顺序不限。

## 数据范围

- `1 <= n <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写英文字母。
- 所有字符串长度之和不超过 `10^5`。

## 示例

### 示例 1

输入：

```text
6
eat tea tan ate nat bat
```

输出：

```text
[[eat tea ate] [tan nat] [bat]]
```

### 示例 2

输入：

```text
1

```

输出：

```text
[[ ]]
```

### 示例 3

输入：

```text
3
abc bca cab
```

输出：

```text
[[abc bca cab]]
```

## 函数签名

```go
func groupAnagrams(strs []string) [][]string
```

## 解题提示

可以为每个字符串生成一个“字母频次”作为哈希表的键。拥有相同键的字符串属于同一组。

## 复杂度目标

- 时间复杂度：`O(S)`，其中 `S` 是所有字符串长度之和。
- 空间复杂度：`O(S)`。
