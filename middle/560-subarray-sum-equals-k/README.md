# 560. 和为 K 的子数组

- 难度：中等
- LeetCode 链接：https://leetcode.cn/problems/subarray-sum-equals-k/

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的连续子数组的个数。

子数组是数组中元素的连续非空序列。

## 示例

### 示例 1

输入：`nums = [1,1,1], k = 2`

输出：`2`

### 示例 2

输入：`nums = [1,2,3], k = 3`

输出：`2`

### 示例 3

输入：`nums = [1,-1,0], k = 0`

输出：`3`

## 数据范围

- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`

## 解题提示

使用前缀和和哈希表记录前缀和出现的次数。当前前缀和为 `sum` 时，之前出现过的 `sum-k` 可以与当前位置组成和为 `k` 的连续子数组。
